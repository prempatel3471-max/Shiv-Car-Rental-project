# 🚗 Shiv Car Rental

Shiv Car Rental is a full-stack web-based car rental management system developed using HTML, CSS, JavaScript, PHP, and MySQL.

## Features

- 🚘 Browse available cars
- ⏱️ Select rental hours
- 📅 Select pickup date and time
- 🔍 Check car availability
- 🚫 Automatically prevent overlapping bookings
- 💵 Cash-at-pickup payment
- 📋 Booking management
- 🔐 Admin dashboard
- 💳 Admin control over payment status
- 🚗 Admin car management
- 🗄️ MySQL database integration
- 📱 Responsive user interface

## Technologies

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- XAMPP

## Project Purpose

The project provides a simple and efficient platform for customers to rent cars while allowing administrators to manage vehicles, bookings, availability, and payment status from a centralized dashboard.
